# SwiftMark — fast markdown renderer

A dependency-free, single-pass CommonMark 0.31.2 + GFM 0.29 renderer that
matches marked 18.1.3 output, built for the make.fun markdown-render-speed-02
bounty. `parse.js` exports `parse(markdown)`; `main.ts` renders every case in
`/input/cases.json` to `/output/html.json`.
